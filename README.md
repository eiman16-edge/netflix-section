# Netlinks

A modern React + Vite landing page for NETLINKS, an enterprise technology company based in Afghanistan delivering Odoo, custom software, and AI solutions.

This project presents the company’s brand, service offerings, industry expertise, client trust indicators, FAQs, and conversion-focused call-to-action sections in a polished single-page experience.

## Features

- Responsive marketing landing page
- Hero section with strong value proposition and CTAs
- Services, platform, and industry highlights
- Client logos and trust-building proof points
- FAQ accordion and final conversion section
- Footer with navigation and contact information
- Built using React and Vite for fast development and deployment

## Tech Stack

- React 19
- Vite
- JavaScript
- CSS for component styling
- GitHub Pages deployment support via `gh-pages`
